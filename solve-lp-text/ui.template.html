LP // ONE-SHOT CPLEX TEXT SOLVER highs.solve()

Solve a model from LP text

Use this entry point when a linear programming model already exists in CPLEX LP format, or when generating readable model text is simpler than assembling sparse arrays. solve() parses and solves the text in one call, then returns a name-keyed result with the objective, column values, row values, duals, and basis statuses. It reparses the model on every call; use a persistent model for repeated solves or incremental changes.
